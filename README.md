# Question 1:
When using the Perspective Camera, what happens to objects farther away?

# Answer: 
When using the Perspective Camera, objects that are farther away from the camera appear smaller than objects that are closer to the camera.

# Question 2:
When using the Orthographic Camera, what happens to object size as distance increases?

# Answer:
When using the Orthographic Camera, the size of an object doesn't change no matter the distance from the camera. For example, both my tree and the back rock have a width of 2 (x), and both appear the same size in the orthographic view despite being at different z values.

# Question 3:
Which camera looks more like real life?

# Answer:
The Perspective Camera looks more similar to real life, as when we look at things in real life we perceive objects that are further away as being smaller, which is what the Perspective camera does that the Orthographic one doesn't. Whereas the orthographic one looks like a scene from a video game, the perspective one has depth and looks more like real life.

# Question 4:
Which camera would be best for:

A. First-Person Shooter
Why?

B. Technical Blueprint Software
Why?

C. Strategy Game such as Civilization
Why?

# Answer:
A. Perspective camera would be best for a first-person shooter, as it's important in a first-person game to be able to perceive depth. This will make it much easier to move your character where you want to go, and aiming will be more accurate.
B. Orthographic would be better for a technical blueprint software, because technical diagrams need to be able to accurately display lengths rather than distort them.
C. Depending on how the game works, either could work, but for a top-down style game like Civ, orthographic would be better so that each tile appears the same size despite distance from the camera. This will keep the game even and readable.

# Question 5:
What is the biggest advantage of Orthographic cameras?

# Answer:
The biggest advantage of Orthographic cameras are that they don't distort the lengths and distances of objects in the scene, keeping them accurate to design and easily readible by the viewer.
